This document outlines the policy for using the name and branding associated with this project.

## Protected Marks

The trademarks covered by this policy include:
* The project name: **TRAILSPACE FILE SERVICE** also known as 'TFSF'
* The project logo, banner, icons, and official graphics
* Any names of sub-projects or associated tools maintained in this repository

## Allowed Uses (No Explicit Permission Required)

You may use the project name or logo without formal permission under the following circumstances:

1. **Nominal and Descriptive Use:** You may use the name to truthfully refer to or describe this software (e.g., *"Built with TRAILSPACE FILE SERVICE"*, *"Compatible with TRAILSPACE FILE SERVICE"*, or *"Tutorial: How to install TRAILSPACE FILE SERVICE"*).
2. **Linking to the Repository:** You may use the logo or name on a personal site, blog, or repository to link directly to this official GitHub project.
3. **Unmodified Distribution:** You may use the name to identify original, unmodified binaries or source code packaged directly from this repository.

## Restricted Uses (Requires Permission or Revision)

You **may not** use the project name or logo in any way that suggests endorsement, sponsorship, or official affiliation where none exists. Specifically:

* **Modified Forks and Derivative Works:** If you fork, modify, or re-distribute this software under your own changes, you **must change the name and logo** so that users do not confuse your version with the official project.
* **Domain Names and Social Accounts:** You may not register domain names, social media handles, or organization names that incorporate the project name without prior written consent.
* **Commercial Branding:** You may not sell merchandise, software products, or services using the project's name or logo as the primary branding without permission.
* **Confusingly Similar Names:** You may not use a name or logo that is confusingly similar to the project's marks.
